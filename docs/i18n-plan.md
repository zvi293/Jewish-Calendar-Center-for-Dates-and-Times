## הכרעות סופיות (30/09/2026)

1. **תוכן בלי אנגלית → מוסתר במצב `en`**, חוץ ממה שיתורגם ידנית. כל ספר/כרטיס/מודול מקבל דגל `en: true | false | "manual"`. `"manual"` = טקסט אנגלי מתוחזק ידנית ב-`i18n/en-content.js` (נטען עצל, רק ב-`en`, רק כשנפתח). תרגום ידני (לוח ברכות, סיפורי הבעש"ט, הילולות) — **רק אם המשתמש יבקש בהמשך**, לא בהיקף הראשון.
2. **נוסח באנגלית: לשאול בפעם הראשונה**, רק Ashkenaz / Sefard (`ensureNusachChosen`, `script.js` ~24632, מקבל רשימת נוסחים לפי שפה). משתמש שעובר לאנגלית עם נוסח עדות המזרח שמור → נשאל מחדש.
3. **SEO: בורר בתוך האפליקציה בלבד.** אין `/en/`, אין hreflang אנגלי, אין שינוי בבלוק ה-SEO / sitemap / llms.txt מעבר לשורה "English UI available".
4. **תרגום וביקורת: Claude בלבד, בשני מעברים נפרדים.** מעבר א' — תרגום המילון בחלקים. מעבר ב' — סשן ביקורת נפרד שקורא את המילון השלם כיחידה: אחידות מונחים (מילון מונחים קבוע ב-`i18n/GLOSSARY.md`: Shacharit, Mincha, Maariv, Plag HaMincha, Sof Zman Kriat Shema, Alos HaShachar, Tzeis HaKochavim, Chol HaMoed, Rosh Chodesh, Yahrzeit, Parashat, Daf Yomi — כמו chabad.org / MyZmanim / OU), אנגלית אמריקאית קריאה, **בלי המצאות** (מונח בלי מקבילה מקובלת נשאר בתעתיק), אורך שמתאים לכפתורים.

### נקודות חיבור לתשתית (מאומתות)
- `CURRENT_LANG` (script.js ~801–802): לקרוא `moadim_lang`, למחוק את הדריסה.
- head script (index.html ~5–17): `lang`/`dir` לפני paint; preload מותנה למילון.
- הטוען `go()` (index.html ~2779–2797): להזריק `i18n/en.js?v=N` **לפני** script.js רק ב-`en` (`initApp()` רץ סינכרונית ב-script.js ~8255). **מלכודת**: ה-regex `versionedRefs` ב-sw.js (~145–151) תופס כל literal `?v=` בסקריפט אינליין — לבנות את ה-URL מחלקים, אחרת כל משתמש עברי יוריד את המילון.

- netlify.toml: `Cache-Control` ל-`/i18n/*` כמו script.js; minify.mjs (רשימה קשיחה); tailwind.config.js content (אם יש שמות class).

## ביצועים — למה זה בטוח
1. **משתמש עברי: 0 בייטים נוספים.** `i18n/en.js` נטען רק ב-`en`.
2. **לא מכפילים את script.js.** התפילות המוטמעות לא מתורגמות; באנגלית הבונים לא נקראים.
3. מילון ~40–50KB Brotli, ~8% ממשקל script.js הדחוס.
4. `t()` = גישה למאפיין. אפס השפעה על TBT/INP.
5. **החלפת שפה = `location.reload()`** — בלי `applyTranslations` על DOM חי.

סיכוני רגרסיה (לא ארכיטקטורה): CLS ב-LTR (`scrollbar-gutter`/`rel=expect` כוונו ל-RTL — לאמת ב-PageSpeed); תפילה אנגלית מספריא איטית מטקסט מוטמע — prefetch + `RUNTIME_CACHE`.

## ארכיטקטורה
- **מפתחות המילון = המחרוזת העברית עצמה** (gettext): `t("לוח שנה חודשי")`; בעברית `t = s => s`; אינטרפולציה `t("בעוד {n} ימים", {n})`. המילון `{"לוח שנה חודשי": "Monthly calendar"}`.
- `i18nDict`/`dynamicUiDict` הקיימים נבלעים למנגנון החדש.
- מודולי תוכן עם דגל `en`; מה שאין לו — מוסתר.
- קורא באנגלית: אותו `_sefariaJson`, `version=english` (v3) / `text` (v1); מספור `1, 2, 3`; `dir="ltr"`; מפרשים כבלוק אחרי הפסקה.
- תפילות באנגלית: צינור רזה על `FULL_PRAYER_SECTION_REFS` — Siddur Ashkenaz / Sefard.
- תאריך עברי: `Intl.DateTimeFormat("en-u-ca-hebrew")`.
- RTL→LTR: מאפיינים לוגיים רק במקומות שנמדדו; לא לגעת ב-`html.dark` (תלוי ב-`[style*=...]` מילוליים) בלי בדיקה.
